♿ Accessibility & i18n Commitments

🌐 3 Languages: English, Español, Français — All labels, alt text, and aria attributes support language switching via JSON dictionaries.

🎯 WCAG 2.1 AA: Minimum contrast ratio 4.5:1 for text, 3:1 for large text. Focus rings always visible.

⌨️ Keyboard navigation: Full tab order, skip link, arrow key navigation for fretboard diagrams.

📱 Responsive: Touch targets ≥ 44px, no horizontal scroll on mobile.

🧠 Screen reader: Semantic HTML, live regions for tuner, chord names read as text.
